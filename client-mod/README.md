# RpgCore — клиентский мод

Только презентация: полоса ресурса, значки статусов, перезарядки слотов. Мод
ничего не решает и ничего не присылает серверу, кроме рукопожатия, — поэтому
плагин полностью работоспособен без него, а мод нельзя использовать, чтобы
что-то получить.

## Чего здесь нет

Нажатий. Навыки применяются сочетанием Shift и цифры, которое перехватывает
сервер (`SkillInputListener`). Это сознательно: если бы нажатия шли через мод,
игрок без мода остался бы без навыков, то есть мод стал бы обязательным.

## Сборка

Мод **не входит** в корневую сборку `rpgcore`: для него нужна сеть, чтобы
выкачать NeoForge и его зависимости, а плагин собирается офлайн. Поэтому
`settings.gradle.kts` его не включает, и `./gradlew build` в корне его не
трогает.

Собирать отдельно, из этого каталога:

```
gradle build
```

Первая сборка требует сети. Нужен JDK 21 и NeoForge для 1.21.1.

## Протокол

Файлы `src/main/java/ru/projectst/rpgcore/net/` — **копия** классов из плагина.
Это сознательное дублирование: общий модуль заставил бы мод зависеть от сборки
плагина, а плагин — тащить сборку мода. Копия защищена тем, что формат проверен
тестами в плагине и несёт версию в первом байте каждого сообщения: при
расхождении версий сервер отказывает словами, а не присылает мусор.

При изменении формата: поправить `Protocol.VERSION` в плагине, скопировать оба
файла сюда, собрать мод заново.
