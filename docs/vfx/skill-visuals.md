# Визуальные описания навыков

Это сценарий того, как выглядит каждый навык: что появляется в мире, что на
теле, что на экране и что слышно. Пишется словами, а не кодом. Реализация идёт
по `docs/prompts/skill-vfx-unique.md`, пилот — друид.

Решения владельца:
- 3D-объекты рисует **мод** сам (корни, цепи, клинки, щиты, руны, черепа);
  сервер присылает только событие с числами.
- Слои: **объекты в мире**, **эффекты на теле**, **экранные эффекты** (видит
  только сам игрок, отключаются в настройках), **свои звуки**.
- Пилот — **друид** целиком, затем остальные классы по образцу.

---

## 0. Правила, общие для всех

**Граница области — всегда правда.** Корни, лозы, волны и стены могут быть
сколь угодно живыми, но у каждой области остаётся читаемая черта ровно на
радиусе из события (радиус уже со статом `skill_radius`). Корни вырастают
*внутри* круга и упираются в его край, а не выходят за него. Срок зоны — по
событию (уже с тем, что решит сервер), конус — по углу выборки.

**Сначала что, потом как красиво.** У каждого навыка три такта:
1. *Замах* (0–4 тика) — короткий знак «сейчас будет»: вспышка у рук, руна под
   ногами, натяжение тетивы.
2. *Удар* — сам эффект; граница видна в этот момент обязательно.
3. *След* (до 1–2 секунд) — то, что осталось: корни уходят в землю, дым тает,
   цепь рассыпается. Механика на этом уже не держится, это память о ударе.

**Состояние видно на том, на ком оно висит.** Корни держат — значит, у ног
цели корни, пока висит статус `root`, и уходят ровно тогда, когда он снят.
Это отдельный слой (раздел 2), общий для всех навыков: оглушение от рыцаря и
от ударника выглядит одинаково.

**Класс узнаётся с первого взгляда.** Облик класса (цвет, блик, форма искр) из
`FxStyle.Look` остаётся — объекты добавляются поверх, а не вместо.

**Экранные эффекты — мягкие.** Тряска не больше 0,3 блока и не дольше
0,4 секунды, вспышка по краям экрана не закрывает центр, всё выключается
одним переключателем в настройках мода, а «Минимум» в «Частицах» выключает их
сам. Видит только тот, кого это касается: тряску от землетрясения — те, кто в
радиусе, вспышку крита — тот, кто ударил.

**Звук.** Свои звуковые события в ресурсах мода (`sounds.json`). Пока своих
`.ogg` нет, событие собирается из ванильных сэмплов: слои, высота, разброс.
Игрок с модом получает свой звук, без мода — ванильный, как сейчас; дважды не
слышит никто.

**Нагрузка.** Объект в мире — это модель из готовых блоков и простой
геометрии, без новых записей в реестрах. На «Меньше» объектов вдвое меньше и
они проще, на «Минимум» — только граница и состояние на цели.

## 1. Библиотека объектов

Общие кирпичи, из которых собираются навыки. Каждый — анимированная модель
с фазами «вырасти → держать → уйти».

| Объект | Из чего | Как живёт |
|---|---|---|
| **Корень** | цепочка сегментов из моделей `mangrove_roots` / `hanging_roots`, изгиб сплайном | пробивает землю с осыпью земли, растёт к цели, обвивает ноги, при снятии втягивается обратно с хрустом |
| **Лоза** | тонкие сегменты `vine` / `twisting_vines`, листья-спрайты | хлёстко выбрасывается из земли, бьёт и опадает |
| **Цветок / бутон** | модели `spore_blossom`, `pink_petals`, `flowering_azalea` | раскрывается, качается, роняет пыльцу |
| **Кора** | одревесневшие лианы (`oak_log`), спиралью вокруг тела на расстоянии | вьётся из земли снизу вверх, медленно кружит, при ударе внешний виток осыпается щепой |
| **Цепь** | звенья `chain`, провисание по цепной линии | вылетает, звенит, натягивается, рвётся на звенья |
| **Клинок** | плоская модель меча/кинжала (предмет в руке, `iron_sword`) | летит, вращается, втыкается в землю и тает |
| **Щит** | модель предмета `shield`, увеличенная, полупрозрачная | поднимается перед носителем, гудит при ударе, даёт трещину |
| **Знамя** | модель `white_banner` в цвете класса | вбивается в землю, полотно колышется |
| **Руна / печать** | плоские круги с глифами (текстура `runes`) | вращаются, вспыхивают, раскалываются |
| **Череп / душа** | модель `skeleton_skull` / `wither_skeleton_skull`, дымка `soul` | летит по дуге, сгорает |
| **Стрела** | модель стрелы, шлейф | летит, втыкается, дрожит |
| **Двойник** | силуэт носителя, полупрозрачный, без лица | мерцает, рассыпается на звёзды |
| **Трещина** | тёмная полоса по земле с подсветкой изнутри | разбегается от центра, затягивается |
| **Волна земли** | кольцо из приподнятых «блоков» земли под ногами | поднимается и опускается бегущей волной |
| **Дым / пыль** | крупные мягкие спрайты `wisp` | клубится, медленно расползается до границы и тает |

## 2. Состояния на цели

Рисуются, пока статус висит; уходят, когда снят. Сервер сообщает «на этом
существе такой-то статус на столько-то тиков, наложил такой-то».

| Статус | Как выглядит |
|---|---|
| `root` Корни | 3–4 корня вырастают у ног, обвивают голени, подрагивают; при снятии лопаются и уходят в землю |
| `stun` Оглушение | три звёздочки кружат над головой, голова чуть покачивается |
| `silence` Тишина | тусклая перечёркнутая руна у рта, искры класса гаснут |
| `banish` Изъятие | кокон из тёмного стекла с прожилками, внутри силуэт, звуки приглушены |
| `slowed` Замедление | под ногами вязкая тёмная лужа, шаги оставляют тянущийся след |
| `exposed` Уязвимость | треснувший полупрозрачный щит, мигающий на груди |
| `weakened` Ослабление | серые нити стекают с рук |
| `bleed`, `berserk_bleed` | капли крови падают с цели раз в тик урона, на земле остаются пятна |
| `venom` Трупный Яд | зелёные пузыри поднимаются с плеч, кожа будто тлеет |
| `curse` Иссушение | лиловая дымка выходит из груди и тянется к колдуну |
| `rot` Гниющая рана | наконечник торчит из раны, вокруг — бурые споры |
| `challenge` Вызван | герб класса (меч или щит) над головой, тонкая нить к рыцарю или воину |
| `reaper_brand`, `reaper_mark`, `death_mark`, `karma_mark`, `quarry` | свои знаки над головой: коса, серп, череп, инь-ян, перекрестье — видят свои и сам наложивший |
| `chains` | цепь от груди цели к колдуну, натягивается при подтяжке |
| `bark_guard` Кора | лианы спиралью вокруг тела, не касаясь его; на втором заряде — второй виток навстречу |
| `shield` Щит | тонкая сфера вокруг, вспыхивает при поглощении |
| `veil`, `ambush`, `executioner`, `feigned` | невидимость: дрожащий воздух по контуру, видят только свои |
| `growth` / `wither` | у друида: зелёные или бурые листья на плечах, по листу на стак |
| `soul` | у колдуна: огоньки душ кружат вокруг, по огоньку на душу |
| `shadow` | у убийцы: тёмный шлейф за руками, гуще со стаками |
| `heat` / `overheat` | у берсерка: угли на плечах; перегрев — пламя по контуру |
| `stance_*` | у ударника: свой символ стойки под ногами |
| `rage`, `hunger`, `undying`, `unshakable`, `asura` и прочие баффы | своя аура в цвете класса, подробно у навыков ниже |

## 3. Друид — пилот

> **Сделано** (протокол 10): сцены всех шести навыков, корни/кора/звёзды/яд/
> листья на целях, волки с шипами и цветком, цветок бездны по фазе, подготовка
> каста, предупреждения у корней и плюща, звуки. Не проверено глазами в игре.

Облик: живая зелень, листья, солнечный блик. Звуки: шорох листвы, треск
корней, глухой удар земли, гул под землёй.

### Хватающие корни `druid_grasping_roots`
*Механика:* все враги в радиусе получают урон и корни (`root`); на трёх Роста
держат дольше; копит Увядание.
- **Замах:** друид бьёт посохом о землю, от точки удара разбегается трещина
  кольцом до границы.
- **Мир:** из трещины по всей площади пробиваются корни с осыпью земли: у
  каждого врага — свой пучок из 3–4 корней, которые тянутся к нему и
  обвивают ноги. В пустых местах круга — короткие корни, которые вырастают и
  сразу уходят, чтобы было видно всю площадь. По краю — граница из
  сплетённых тонких корешков ровно на радиусе.
- **Тело:** у пойманных корни держатся ровно столько, сколько висит `root`;
  с Ростом корни толще, с листьями и шипами.
- **Экран:** у пойманного игрока низ экрана затягивают тени корней на время
  статуса.
- **Звук:** треск ломающейся земли, скрип натягивающихся корней; при снятии
  — сухой хруст.
- **Числа:** радиус — граница трещины и край корней; срок — жизнь корней на
  цели.

### Отравленный плющ `druid_poison_ivy`
*Механика:* лозы бьют по площади: урон, оглушение, яд; на трёх Роста — шире и
с замедлением.
- **Замах:** под ногами вспыхивает зелёно-лиловый узор из листьев.
- **Мир:** от друида во все стороны хлещут лозы плюща — 8–12 штук, каждая
  выстреливает из земли дугой и бьёт по цели или в землю у края круга. Где
  ударила — лужица ядовитых спор. Усиленный: лоз вдвое больше, по краю
  вырастает живая изгородь плюща на секунду.
- **Тело:** оглушённые — звёздочки (общий `stun`), отравленные — зелёные
  пузыри до конца яда; замедленные — вязкие листья у ног.
- **Экран:** у задетого игрока краешки экрана зеленеют на время яда.
- **Звук:** свист и хлёст лоз, шлепок о землю, шипение спор.
- **Числа:** лозы достают ровно до границы, у усиленного — до усиленной.

### Споры жизни `druid_life_spores`
*Механика:* лечит друида и союзников в радиусе; на трёх Увядания споры ещё и
разъедают врагов; копит Рост.
- **Замах:** у ног распускается крупный бутон `spore_blossom`.
- **Мир:** бутон лопается и выпускает облако золотистых спор, которое мягко
  расползается до границы и висит секунду. С Увяданием в облаке вспыхивают
  бурые споры, которые тянутся к врагам и прилипают.
- **Тело:** на вылеченных — поднимающиеся золотые искры и маленькие листья;
  на разъеденных врагах — бурые точки.
- **Экран:** у вылеченного игрока — тёплое свечение по краям на полсекунды.
- **Звук:** мягкий хлопок бутона, звенящий шорох спор.
- **Числа:** облако упирается в радиус.

### Кора `druid_bark_guard`
*Механика:* кора гасит один удар целиком и оглушает ударившего; на трёх
Увядания — два удара; копит Рост.
- **Мир:** из земли у ног друида поднимаются одревесневшие лианы и вьются
  спиралью вокруг него, не прилегая к телу.
- **Тело:** лианы держатся, пока висит `bark_guard`, медленно кружат и ходят
  за друидом; при погашенном ударе внешний виток уходит, осыпается щепа, к
  ударившему летит щепка и оглушает его (общий `stun`). При двух зарядах —
  два витка навстречу друг другу.
- **Экран:** у друида при погашенном ударе — глухой «тук» и тень коры по
  краям.
- **Звук:** скрип дерева при наращивании, сухой треск при поглощении.

### Зов зверя `druid_beast_call`
*Механика:* волк-спутник на минуту: с тремя Увядания — боевой, с тремя Роста —
опекающий, лечит.
- **Мир:** перед друидом расходится круг из листьев, в нём из вихря листьев
  собирается волк. Боевой — бурые листья и колючие лозы по спине, опекающий
  — зелёные листья и цветы на загривке.
- **Тело:** у боевого волка — тлеющие бурые глаза и шипы, у опекающего —
  тонкая зелёная нить к друиду; при лечении по нити бежит искра.
- **Звук:** вой в шорохе листвы.
- **Когда уходит:** волк рассыпается листьями.

### Цвет бездны `druid_abyss_bloom`
*Механика:* поле каждую секунду меняет сторону: то лечит своих, то жжёт
чужих; тратит оба счётчика.
- **Мир:** в центре поля из земли вырастает огромный цветок бездны с
  лепестками на всю площадь, его край и есть граница зоны. Фаза
  лечения — лепестки раскрываются и светятся зелёным, над полем поднимаются
  золотые искры. Фаза урона — лепестки закрываются, темнеют до бурого, по
  земле пробегают корни-шипы. Переключение — каждую секунду с волной от
  центра.
- **Тело:** на союзниках в фазе лечения — подъём искр, на врагах в фазе урона
  — бурые шипы у ног.
- **Экран:** у игроков внутри фон по краю экрана мягко дышит в цвет фазы.
- **Звук:** низкий гул раскрытия, пульс на каждую фазу.
- **Числа:** лепестки по радиусу зоны, цветок держится весь её срок.

## 4. Маг

> **Сделано** (`ScenesMage`): руны вокруг разряда, разрыв пустоты от
> усиленного, осколок аметиста в россыпи, кольцо петли в воздухе, воронка
> сгона, рунные оковы вместо корней (статус `root` от мага), отпечаток мага на
> старте шага, сфера печатей и взрыв коллапса, свои звуки, каст по навыку.
> Не проверено глазами в игре.

Облик: аркана, синие и фиолетовые звёзды, руны. Звуки: стеклянный звон,
гудение, хлопок воздуха.

### Мановый разряд `mage_mana_bolt`
- **Мир:** сгусток маны с орбитой из трёх рун летит по прямой; на
  попадании — звёздный всплеск; там, где кончился, ложится печать (вращающийся
  круг рун). Усиленный: крупнее, с фиолетовым ядром, пробивает цели — на
  каждой пробитой остаётся след-разрыв.
- **Тело:** рука мага вспыхивает в момент выстрела.
- **Звук:** звон, свист полёта, стеклянный хлопок.

### Петля потоков `mage_flow_loop`
- **Мир:** кольцо маны разворачивается от мага до границы, по пути
  отбрасывая врагов; под ногами — печать. На своей печати: кольцо двойное,
  по краю бегут руны, а печать под ногами раскалывается и подпитывает волну.
- **Экран:** лёгкий толчок камеры при усиленном.
- **Звук:** нарастающее гудение и хлопок.

### Сгон `mage_herd`
- **Мир:** впереди встаёт печать, от неё к магу раскрывается конус-воронка
  из светящихся лент; ленты тянут врагов к печати. На своей печати: шире, и
  в конце из печати выстреливают цепи рун и приковывают пойманных (`root`
  рунный: кольца рун вокруг ног вместо корней).
- **Звук:** всасывающий гул, звон цепей рун.

### Россыпь `mage_scatter`
- **Мир:** веер из 3 (или 5 на печати) кристалликов-осколков летит по дуге,
  каждый втыкается в землю и раскрывается печатью.
- **Звук:** серия коротких звонов, как бусины.

### Шаг в пустоту `mage_void_step`
- **Мир:** маг распадается на звёзды в точке старта, ленту пустоты видно
  от старта до прибытия, в точке старта остаётся печать-якорь. На печати:
  вдвое дальше и в точке прибытия — волна пустоты по радиусу.
- **Экран:** короткое растяжение по краям экрана при переносе.
- **Звук:** всасывание и хлопок.

### Коллапс `mage_collapse`
- **Мир:** все печати мага поднимаются над землёй и летят к точке взгляда,
  волоча за собой врагов; над точкой собирается сфера из печатей; секунду
  она сжимается и пульсирует (граница удара видна всё это время), затем
  схлопывается взрывом. Чем больше печатей, тем крупнее сфера и ярче взрыв.
- **Экран:** у тех, кто внутри, — затягивание к центру экрана, затем вспышка.
- **Звук:** нарастающий хор, тишина на долю секунды, удар.

## 5. Колдун

> **Сделано** (`ScenesWarlock`): череп иссушителя в полёте, дымка
> проклятия к колдуну и душа обратно, души по стакам, серп над целью
> (незеритовая мотыга) со взмахом при жатве, теневая цепь до цели, пелена с
> глазами (ока Края) и тьмой на экране внутри, струи душ при переливании, щит
> из душ, кокон из тонированного стекла и цепи, свои звуки, каст по навыку.
> Не проверено глазами в игре.

Облик: скверна, лиловая дымка, ядовито-зелёные блики, души. Звуки: шёпот,
стон, треск тёмного огня.

### Проклятый снаряд `warlock_cursed_bolt`

- **Тело:** цепь держится, пока висит `chains`; на каждой подтяжке

- **Тело:** невидимость.
- **Экран:** у убийцы мир на секунду уходит в серое.

### Ответный Клинок `assassin_riposte`
- **Тело:** у убийцы перед грудью висит тёмное лезвие остриём вперёд, пока
  открыто окно; на ответе лезвие бьёт в ударившего.
- **Звук:** звон стали, металлический лязг ответа.

### Каскад Теней `assassin_shadow_cascade`
- **Мир:** три прыжка: на каждом — тёмная вспышка у цели и лента тени от
  прошлой точки к новой; цели, уже задетые, отмечены тусклой меткой, чтобы

- **Звук:** три нарастающих удара.

### Час Палача `assassin_executioners_hour`
- **Тело:** убийца в тёмном ореоле, за ним тянется шлейф, глаза горят

- **Экран:** мир чуть темнее и краснее по краям на всё время.
- **Звук:** низкий удар колокола в начале и при каждом добивании.

### Казнь `assassin_execute`
- **Мир:** над добиваемым — тёмная гильотина-клинок падает сверху.
- **Звук:** свист и глухой удар.

### Карнавал `trickster_carnival`

- **Мир:** рывок вперёд, за кулаком — хвост молнии; из Покоя — дальше и с
  громовым хлопком в конце.
- **Звук:** свист, удар грома.

### Подсечка `striker_sweep_kick`
- **Мир:** круговая дуга от ноги по земле до границы.
- **Тело:** у оглушённых — `stun`.
- **Звук:** свист, глухой удар.

### Дрожь Ветра `striker_wind_flurry`
- **Мир:** 3 (или 5) быстрых кулака-силуэта бьют по конусу один за другим.
- **Звук:** серия хлопков.

### Выброс Энергии `striker_chi_blast`
- **Мир:** шар энергии с молниями по прямой; из Бреши — пробивает броню:
  на цели вспыхивает треснувший щит.
- **Звук:** гул, разряд.

### Воздушный Апперкот `striker_rising_dragon`
- **Мир:** удар снизу вверх, за кулаком — вихрь-дракон из ветра поднимает
  цель.
- **Звук:** восходящий свист, рык дракона.

### Касание Кармы `striker_touch_of_karma`
- **Тело:** на цели — знак инь-ян, вращается быстрее к моменту взрыва; взрыв
  — белая вспышка.
- **Звук:** тихий колокольчик, затем удар.

### Уклонение `striker_phantom_step`
- **Мир:** кувырок, на месте — призрачный силуэт, через который проходят
  удары.
- **Звук:** порыв.

### Стойка Дзэн `striker_zen_meditation`
- **Тело:** ударник замирает, вокруг — медленно вращающийся круг с
  иероглифом, листья падают и останавливаются в воздухе.
- **Экран:** мир чуть замедляется визуально (мягкое размытие краёв).
- **Звук:** гонг, тишина.

### Режим Асуры `striker_asura_mode`
- **Тело:** за спиной появляются две призрачные пары рук, повторяющие удары;
  каждый удар даёт всплеск по ближним.
- **Экран:** золотистая рамка.
- **Звук:** низкий гул, на каждом ударе — эхо.

## 12. Рыцарь

Облик: свет, бледное золото, щиты. Звуки: колокол, звон доспеха, гул щита.

### Вызов `knight_challenge`
- **Мир:** от рыцаря по конусу летит световое копьё-знак.
- **Тело:** `challenge` на целях: герб-щит над головой и нить к рыцарю.
- **Звук:** звон удара меча о щит.

### Клич `knight_war_cry`
- **Мир:** световая волна от рыцаря до границы, над ним вспыхивает знак.
- **Тело:** `challenge` у всех задетых.
- **Звук:** боевой клич, звон.

### Ударная Волна `knight_shockwave`
- **Мир:** рыцарь бьёт щитом о землю, вперёд по конусу бежит волна земли со
  светлой кромкой; вызванных подбрасывает выше.
- **Экран:** тряска у задетых.
- **Звук:** удар, раскат.

### Заступник `knight_protector`
- **Мир:** рыцарь рывком перемещается к союзнику, за ним — золотой след.
- **Тело:** на союзнике — полупрозрачный щит (`guarded`), у бивших — вызов.
- **Звук:** звон, гул щита.

### Карающий Щит `knight_shield_bash`
- **Мир:** призрачный щит бьёт перед рыцарем, на цели — вспышка-печать.
- **Звук:** тяжёлый звон.

### Глухая Оборона `knight_shield_wall`
- **Тело:** перед рыцарем поднимается стена из 3 призрачных щитов; чем
  больше вызванных вокруг, тем больше щитов и ярче стена.
- **Звук:** гул щитов.

### Возмездие `knight_retribution`
- **Тело:** вокруг рыцаря вращаются три светящихся меча остриём наружу;
  на ответе мечи бьют в ударившего.
- **Звук:** звон, тройной удар.

### Знамя `knight_banner`
- **Мир:** знамя рыцаря вбивается в землю, полотно колышется; круг зоны
  размечен светлыми камнями по краю.
- **Тело:** у союзников внутри — `banner_guard` (знак знамени на груди), у
  вошедших врагов — вызов.
- **Звук:** удар древка, хлопанье полотна.

### Абсолютная Фортеция `knight_absolute_fortress`
- **Мир:** вокруг рыцаря поднимается купол из светлых каменных стен до
  границы, стены полупрозрачные.
- **Тело:** все вызванные соединены нитями с рыцарем.
- **Экран:** у рыцаря — ровная золотая рамка.
- **Звук:** низкий колокол.

### Правосудие `knight_judgment`
- **Мир:** над каждым вызванным с неба падает световой меч; чем больше
  вызванных, тем крупнее мечи.
- **Экран:** у задетых — вспышка.
- **Звук:** хор, удары.

## 13. Воин

Облик: сталь и огонь, оранжевые угли. Звуки: лязг, хрип, удар.

### Рассекающий Удар `warrior_cleave`
- **Мир:** широкая огненная дуга по конусу.
- **Звук:** тяжёлый мах.

### Натиск `warrior_charge`
- **Мир:** разбег с пылью из-под ног, на столкновении — ударная вспышка, цель
  отлетает.
- **Звук:** топот, удар.

### Таран Щитом `warrior_shield_charge`
- **Мир:** разбег с выставленным призрачным щитом, на столкновении — щит
  вспыхивает.
- **Тело:** у сбитого — `stun`.
- **Звук:** топот, гулкий удар.

### Поднять Щит `warrior_shield_up`
- **Тело:** перед воином большой полупрозрачный щит, при попадании — искры.
- **Звук:** лязг.

### Круговой Удар `warrior_spin`
- **Мир:** круговая огненная дуга до границы.
- **Звук:** свист.

### Связка `warrior_combo`
- **Мир:** три дуги подряд; третья — вдвое шире и ярче, если первые две
  попали; над воином — три засечки, которые зажигаются по попаданиям.
- **Звук:** три удара, третий — тяжелее.

### Вызов на бой `warrior_challenge`
- **Тело:** `challenge`: огненный герб-меч над головой.
- **Звук:** звон.

### Ярость `warrior_rage`
- **Тело:** воин в огненной ауре, струйка крови с руки (плата).
- **Звук:** рык.

### Стойка `warrior_stance`
- **Тело:** воин под щитом, каждый принятый удар зажигает засечку на щите;
  в конце — взрыв огня по радиусу, тем сильнее, чем больше засечек.
- **Экран:** тряска у задетых взрывом.
- **Звук:** удары по щиту, затем рёв и взрыв.

### Боевой Клич `warrior_war_cry`
- **Мир:** волна от воина до границы, над союзниками вспыхивают огненные
  знамёна.
- **Тело:** `unshakable` у союзников.
- **Звук:** клич.

## 14. Прочее

### Рывок `dash`
- **Мир:** короткий след-ветер из светлой дымки по ходу движения.
- **Экран:** лёгкое растяжение по краям.
- **Звук:** порыв.

### Предметы
- **Импульс арканы** `item_arcane_pulse`: золотой сгусток с орбитой рун,
  всплеск на попадании.
- **Укол из тени** `item_shadow_nick`: короткий тёмный росчерк по цели.
- **Вытяжка** `item_soul_drain`: из проклятых врагов к носителю тянутся
  золотые струйки, на нём — подъём.

### Мобы
- **Песчаный выброс** `mob_sand_burst`: из-под моба вырывается кольцо
  песка до границы, песок оседает.
- **Жало** `mob_venom_sting`: зелёный укол, `venom`-пузыри на цели.

### Попадание и крит (у всех)
- **Попадание:** вспышка цвета класса и искры мотива.
- **Крит:** белое ядро, лучи, волна у ног; **экран** ударившего — короткая
  вспышка по краям; **звук** — свой звонкий хруст поверх ванильного крита.
